# Changelog

## 0.1.2

- Add the hand-drawn LDOC logo as the extension icon.

## 0.1.1

- Automatically open preview when a .ldoc file becomes active, retaining editor focus.
- Add the autoPreview setting and avoid reopening on repeated focus events.
- Correct the extension display name separator.

## 0.1.0

First public version of LDOC - Living Documents.

- Live .ldoc preview with styled prose and animated RoughJS diagrams.
- Processes, cycles, decisions, comparisons, conversations and simple technical flows.
- Outline mind maps with surrounding branches and content-aware box sizing and spacing.
- Thirteen built-in object kinds and hand-drawn figures.
- Offline standalone HTML export with bundled renderer and handwritten font.
- Optional AI authoring with Anthropic, OpenAI, Gemini or a compatible endpoint.
- Guided provider setup, secure provider-specific key storage and generated-block validation.
